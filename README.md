# instagram

Central de conteúdo e estratégia do perfil [@arayzacavalcante](https://www.instagram.com/arayzacavalcante/): psicologia, literatura e, em breve, clube do livro.

## Estrutura

- `docs/configurar-api-instagram.md`: passo a passo para conectar a API do Instagram
- `scripts/analisar_perfis.py`: gera relatórios de perfis profissionais (seguidores, engajamento, formatos, top posts)
- `analises/`: relatórios gerados
